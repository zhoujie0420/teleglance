# TeleGlance — Even G2 VIP Telegram Inbox & 1-Tap AI Reply Drafter

> **Heads Up: Even Realities Hackathon — Track 01 (Messaging & News) + Special Prize: Best Telegram Integration**
> Triage VIP Telegram chats, scan 30-second channel digests, and send AI-drafted replies in 2 taps on **Even G2** (`576×288` monochrome green) using the R1 Ring.

## Quick Start

```bash
npm install
# Optional: export TELEGRAM_BOT_TOKEN=<your-bot-token> for live Telegram Bot API sync
npm run server   # port 8788
npm run dev      # port 5174
npm test         # Vitest + Even G2 layout compliance tests
npm run build && npm run pack:ehpk
```
